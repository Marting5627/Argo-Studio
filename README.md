Argo Studio 是面向 Apple Silicon Mac 的视频创作工作区。它用一个本地项目串联素材管理、拉片分析、导演创作、画板、视频生成、剪辑和配乐，让参考素材、镜头稿件、生成候选与时间线能够衔接使用。

你可以从一段参考视频、一组图片或一个想法开始：拆解镜头、讨论创意、编写分镜，在画板上组织参考，制作和比较候选，再进入原生时间线完成画面、声音与导出。


Argo Studio 是闭源客户端。本仓库用于发布安装包、更新记录和使用说明，不包含客户端源代码。

## 适合谁

- **短片与广告创作者**：把创意讨论推进到分镜、候选画面与成片。
- **产品和品牌内容团队**：集中使用产品图、人物、场景与风格参考，反复调整不同镜头。
- **AI 视频创作者**：保留提示词、参考与生成记录，比较候选后再决定采用哪一版。
- **需要整理参考与交接项目的人**：从视频中提取切片、截图和分镜表，或将工程与选定素材一起收集。

## 一条可以按需使用的创作流程

**导入素材 → 拉片与参考帧 → 导演与分镜稿 → 画板／工坊 → 剪辑与配乐 → 导出成片**

这些步骤不要求全部走一遍。可以直接导入现有视频进行剪辑，也可以先在导演中讨论创意；画板适合探索画面关系，工坊适合围绕具体镜头比较生成候选。

## 八个创作模块

### 1. 资产：整理整个项目的参考素材

导入本地图片、视频和音频，也可以连接 Eagle 素材库。素材可以作为项目的共同参考，或分配给具体镜头，供后续工作区使用。

- 预览和选择素材，按项目与镜头组织参考。
- 在导演和工坊的文字中通过 `@` 选择具体素材，把参考带进稿件与生成输入。
- 原始文件移动后重新定位缺失素材；需要格式转换时，明确创建兼容副本并保留原件。

例如：把产品图片、人物参考和环境视频放入同一项目，让不同镜头复用同一组视觉依据。

### 2. 拉片：从参考视频提取镜头资料

选择视频与分析范围，使用本地 TransNetV2 或 PySceneDetect 检测镜头边界。检测后可以逐镜浏览、逐帧定位、选择代表帧，并勾选需要保留的镜头。

支持导出：

- **MP4 视频切片**：按选定镜头区间输出，可选择保留或移除原声。
- **PNG 截图**：保留视频画面的实际显示像素尺寸，不使用界面缩略图替代原帧。
- **XLSX 分镜表**：包含镜头缩略图，并保留独立的精确来源信息。

每个镜头选择的代表帧会保存，截图与分镜表使用同一帧。检测结果仍需人工检查；镜头边界检测不等于自动理解剧情或摄影意图。

例如：拆解一支广告的镜头节奏，导出关键画面与分镜表，用于创意讨论或后续画板整理。

### 3. 导演：把创作讨论整理成可编辑的分镜稿

用中文讨论创意、风格、镜头和声音，并通过 `@` 引用项目素材。形成分镜前，可以确认时长、画幅与参考，再生成结构化导演稿。

稿件按视觉风格、角色与服装、素材、场景、时间线和声音等内容组织。既能查看整片，也能进入单个镜头继续编辑。

- 保留不同版本，查看历史并恢复选定内容。
- 将已保存稿件导入工坊，继续制作视频候选。
- 按镜头导入画板，把稿件与参考素材展开排列。
- 按需选择文档型 Skill，为创作提供特定方法或格式；新对话默认不启用。

例如：从一句产品短片想法开始，讨论成片气质和节奏，再逐镜修改动作、构图与声音要求。

### 4. 画板：组织画面、参考与生成结果

把图片和视频放到画板上，移动节点、连接参考，并在节点附近编辑提示词与生成参数。也可以导入已保存导演稿，让镜头内容与所需素材在同一张画板上展开。

- 按镜头分组，整理节点，使用“适合全部”查看整体关系。
- 分别管理图片与视频的生成任务和历史。
- 将结果设为节点预览，加入画板继续作为参考，或导出、加入剪辑资源库。
- 导入新版导演稿时先预览，再选择新增一组或更新已有组。

例如：为同一个场景尝试不同视觉方向，选出合适的图片作为后续视频参考，再把生成结果放回画板比较。

### 5. 工坊：围绕镜头制作和比较视频候选

工坊是视频生成工作区。它可以接收导演稿，也可以使用独立的自定义提示词，在全局或单镜头范围内继续创作。

A、B、C、D 候选可以独立选择与编辑，各自保留输入、参考和任务记录。选择模型后，按该模型实际开放的能力设置时长、画幅和参考方式。

- 在提交前查看当前输入与费用。
- 修改提示词、参考、参数或候选选择后，重新核对费用。
- 浏览生成历史、收藏结果，并明确交付选定版本。
- 先加入素材库，再决定何时放入时间线。

实际可生成的渠道和型号以工作区提示为准；连接或模型目录可见不等于生成执行已经开放。

例如：为一个镜头保留几种不同动作或画面方向，比较完成的候选，再把选中的版本交给剪辑。

### 6. 剪辑：在原生时间线中完成画面与声音

Argo Studio 内嵌 Rudder 原生剪辑工作区。项目素材、生成结果与配乐可以进入同一条时间线。

- **时间线编辑**：多轨、音画链接与解除、片段分割、复制粘贴、吸附、当前轨道波纹删除、标记、撤销与重做。
- **画面调整**：位置、缩放、旋转、裁切、不透明度，以及构图关键帧。
- **调色**：基础参数、色轮、曲线与 LUT。
- **输出**：设置横竖画布和序列尺寸，使用 2K、4K 预设，导出完整成片或指定入点、出点范围。

剪辑内容随 Argo 项目统一保存，切换工作区后仍使用同一份时间线。支持范围取决于具体媒体格式与输出设置。

例如：把生成镜头和实拍素材组合起来，调整镜头长度、叠加画面、配合音乐，输出横版或竖版成片。

### 7. 配乐：从画面或文字开始制作音乐

配乐提供“画面配乐”和“自由创作”两种方式。可以使用图片、视频或当前剪辑作为参考，也可以直接描述需要的音乐氛围与方向，制作纯音乐。

- 试听结果、查看历史任务，或导入已有音频。
- 将选定音乐加入剪辑资源库，再明确放入时间线。
- 当前已接通 Mureka 中国区画面配乐与自由创作；具体型号和费用以实际配置为准。

画面参考的本地文件上传上限为 **10 MB**。生成音乐的长度不一定与参考视频相同，可以在剪辑中继续安排使用范围。

例如：为已有画面寻找音乐方向，或先制作一段氛围音乐，再据此调整镜头节奏。

### 8. Bridges：协助完成项目中的具体操作

Bridges 是 Argo Studio 内的中文助手。它结合当前工程、选区与已开放工具，帮助查询状态、整理内容和执行明确操作。

目前提供的具体流程包括：

- **当前工程健康检查**：列出需要关注的问题。
- **拉片整理到画板**：预览选定镜头的代表帧，再保存素材并整理节点。
- **Shot 生成准备检查**：检查已保存稿件、参数与参考是否准备完整。
- **配乐添加到 Rudder**：把选定配乐放入当前剪辑。
- **软件设置与项目操作**：通过已接通的工具协助处理。

工具与预设可以在设置中查看和管理。执行记录区分已完成、部分完成和仍需核对的步骤；需要确认的操作沿用软件中的确认流程。生成准备检查本身不会提交生成。

例如：选中一组拉片镜头，让 Bridges 帮你整理到画板；或在制作视频前先检查哪些镜头还缺稿件、参数或参考。

## 项目保存与交接

Argo 使用 `.agpk` 本地项目包保存跨工作区内容，包括素材登记、拉片结果、导演稿、画板、生成记录、配乐与剪辑。

普通导入可以引用原始素材，不需要每次保存都复制所有媒体。需要搬移或交接时，使用“收集项目与素材”，选择可读取的素材，生成：

- 一份新的工程；
- 独立的素材目录；
- 记录收集结果的报告。

移动时请保留整个输出目录。未选择或不可读取的素材不会被自动补齐，收集报告会说明实际结果。

项目支持保存与另存；退出时提供“保存／不保存／取消”。新格式兼容要求和缺失引用会明确提示。

## 模型连接

在设置中配置自己的模型服务地址、API Key 和模型，也可以使用提供的服务预设或 New API 自建网关入口。凭据通过系统安全存储管理。

视频渠道可以检测用户已安装的官方 CLI 与连接状态。**连接成功、能读取模型目录、能提交某种生成任务，是不同的状态。** 当前不能将 LibTV、即梦的连接与草稿支持理解为生成执行已开放；实际生成范围以工作区提示为准。

素材整理、镜头检测和项目编辑在 Mac 上进行。使用远端模型创作时，需要对应服务的网络连接和有效授权，并核对提交前显示的输入与费用。

## 公测反馈

欢迎在 [Issues](https://github.com/Marting5627/Argo-Studio/issues) 提交问题与建议。为便于定位，请尽量提供：

- Argo 版本与 build、macOS 版本和芯片型号；
- 出现问题的模块、操作步骤、预期结果与实际结果；
- 去除私人内容后的截图或报错文字。

请勿提交 API Key、令牌或未经处理的私人素材。模型能力、媒体格式与导出组合仍在持续验证，清晰的复现步骤能帮助我们改进后续版本。
