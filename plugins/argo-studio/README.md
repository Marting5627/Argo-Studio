# Argo Studio

桌面客户端的 Argo 素材面板与本机 MCP 整合插件。正式插件版本 0.1.2，要求 Argo 0.4.7.1 或更新的兼容版本。

工程与素材由正在运行的 Argo 管理。插件不直接读取 AGPK，不接收任意本地文件路径，也不保存另一份素材库。

0.1.2 的面板入口独立于工程状态：Argo 未运行时显示“请打开 Argo 并启用本机连接”，不自动启动软件；无工程或未命名工程时提示打开或保存工程；有已保存工程后读取真实素材。关闭 Argo 或工程后，仍可重新打开空面板。工程和素材权限继续由 Argo 校验。

## 使用

**首次安装并启用插件后，请正常退出并重新打开 ChatGPT／Codex 桌面客户端一次，再打开 Argo Studio 面板。** 关闭聊天或右侧面板不能替代这一步。 面板可在没有工程时打开；读取素材和执行工程操作时，再打开并保存对应工程。

1. 在支持本机插件与 MCP Apps 的 ChatGPT 桌面 Work 模式安装并启用 **Argo Studio**。
2. 打开支持该插件的 Argo，在设置中启用本机 MCP。读取素材时，再打开并保存工程。没有显式选择时只查找 `/Applications/Argo.app` 或 `~/Applications/Argo.app`；两个位置同时存在不同安装时，先在 Argo 设置中选择插件宿主。
3. 在侧边打开 **Argo Studio**，查看素材并点击“引用素材”，或者在输入框中使用插件提供的素材提及。
4. 在聊天中提供视频、图片或音频，决定采用后说“把这个视频加入 Argo 素材库”。客户端交出真实附件后，插件传递字节；接受本次操作才由 Argo 原生导入并返回实际编号。
   也可打开聊天文件，在“打开方式”中选择 **Argo Studio**，再核对导入。
5. 双击素材在右侧素材库上方居中浮层预览，面板背景轻微模糊，关闭后恢复。视频和音频保留播放及进度控制；“打开”使用 macOS 为该媒体登记的默认应用，旁边箭头直接列出兼容应用，不先跳到文件页。只有明确选择菜单或右键中的“在新页面播放”（图片为“在新页面查看”）才单独打开客户端文件页。播放不再次导入。

素材区只上下滚动并隐藏滑条，搜索栏与底部引用按钮保持固定。客户端文件页自己的顶部菜单由客户端控制；插件内的“打开”直接调用本机已登记应用，不修改该文件页的栏位或系统默认应用。

右上角可切换“素材库／生成板”。素材库右下“导入素材”从外部选择新文件，接受本次确认后由原生导入保存并返回新编号；取消或拒绝不新增成员。它不把已选素材再复制一份，播放也不会导入。

普通单击切换到当前素材；按住 ⌘ 点击可增减多选。选中后按 ⌘C 复制完整编号，多项按行分隔，再用 ⌘V 粘贴到聊天或文稿；输入框和已选文字的正常复制不受影响。素材库底部左侧为灰色“引用素材”，右侧为“导入素材”。选择和引用按真实对象身份，不按列表位置猜对象。手动刷新重新核对列表和缩略图，刷新时提供忙碌反馈。后台检查保持静默，未变化的内容不重绘；操作或检测到内容更新后续计30秒，连续30秒无操作、无变化即暂停，返回面板操作后恢复同一循环。

生成板按 Shot 查看参数，Global 独立；每个目标只有一套“自定义／导演稿”提示词，A–D只选择本次输出候选。选择候选或来源不清空稿件。点击“覆盖参数”后，经一次客户端确认直接替换并保存，面板显示保存后的参数；拒绝后仍可继续操作。点击“生成候选”仍分别确认必要的报价与生成，不因保存参数自动提交付费任务。

聊天附件成功入库后先刷新当前素材库；客户端提供关闭当前插件页的能力时，才请求关闭这份临时导入页。在临时文件页手动选择文件并成功导入，也走相同的返回动作；从素材库主页选择文件导入则保留主页。没有客户端关闭能力时保留当前素材库，不新建额外页面，也不声称已经切回先前的标签页。取消、拒绝或失败不会关闭当前页。拒绝确认显示“已取消，未加入素材库”，不展示原始回执JSON。

Argo 退出、工程关闭或本地连接关闭后，面板清空旧素材、选择和预览，并关闭播放器。原宿主重开、原工程恢复且授权仍有效时，本地连接会恢复读取；切换到其他工程仍须确认。后台刷新不调用模型。拒绝更换后不会反复询问，可点击素材区的“更换到…”再次准备确认。

素材名称在同一工程内不重名：重复名称自动加 `(1)`、`(2)`，扩展名保持在最后。已有编号和内部身份不变，外部原文件不改名。旧工程的重复名称在读取时统一显示；下一次新增素材时由原保存系统一并保存，不在打开工程时偷偷写入。

当前客户端若不能提供附件字节或引用上下文，会明确显示未完成；可用面板“添加”选择同一文件。备用文件选择不代表聊天附件自动交接已通过。

聊天引用保留每项完整编号及原生资源身份，不附加重复的说明文本。当前桌面客户端用素材名分别显示引用标签；长编号的批次与候选后缀不裁掉。其他 MCP Apps 客户端可能采用自己的引用外观，但资源名称与身份不变。选择引用不会自动发送消息或覆盖正在输入的文字。

导入成功后的聊天标签同样使用新素材的完整编号；保存回执作为结构化信息随附，不再生成名为“文本”的JSON附件。编号取自本次原生结果，并重新核对当前工程成员身份。

## 权限

MCP 先提供区域入口，按当前任务查询某个区域的工具摘要，再读取所需一项的完整合同，不在初始目录返回全部业务 Schema。外部可读取普通界面偏好与状态，但不能修改设置、账户或 Skills，也不能读取本地模型配置、模型绑定、API 地址、代理、密钥状态或本地 CLI 配置。Bridges 自身的原生批准机制不受这项外部限制替代。

外部 MCP 不开放 Argo 内部导演聊天的记录、草稿、上下文或发送工具。外部聊天直接使用全局导演稿预览、正式稿、章节、Shot 和工坊导入工具；内部 Bridges 保留原生导演聊天能力。

图片、视频、音频参考上限在 Argo 设置中共用配置，默认分别为30、10、10。导演按完整稿、画板按节点、工坊按任务对真实素材身份去重计数；不限制素材库总量，不是跨任务共抢的名额。外部入口可读取有效上限，不可修改。接口实际支持的媒体类型和更低上限仍须分别满足，超限不自动丢弃引用。上限变化后旧待批准计划须重新核对。

工坊的业务平台与视频模型名称可以读取，例如 Higgsfield、LibTV、即梦；它们不等于底层接口配置。`generation.businessStatus` 按实际 Shot 返回其所属平台、所选业务模型、对应平台的缓存余额与仍匹配当前输入的有效报价。缓存过期、平台未提供余额、尚未取得或已过期的报价均单独标记，不当作 0。读取不自动查询远端余额、核价、上传或提交生成；需要新的报价时另走原有批准流程。

连接默认读取当前工程的**全部素材库成员**。工坊、画板、拉片和配乐的结果显式入库后同样可见；尚未入库的生成结果不会自动暴露。源媒体仍须通过 Argo 的授权和文件身份检查，缩略图不代替源文件权限。

附件只接收客户端实际提供的字节，不接受任意磁盘路径。每片最多512 KiB，单文件最多1 GiB、临时合计最多2 GiB；顺序、字节数及 SHA-256 由原生端核对。传递不等于入库。工程写入、批准、防重复和保存回执复用同一套原生工具；取消不返回成功。

界面刷新不调用模型、不上传素材、不提交生成。用户引用编号并要求查看、比较或创作时，`argo_read_asset_media` 读取编号对应的原文件；视频同时从这份原文件自动解码最多8帧，带实际时间点，以模型可读的MCP图片内容交付，不用缓存缩略图替代。图片最长边512像素、每帧最多64 KiB，解码在后台执行、最多等待15秒，不保存持久画面缓存。抽样不能证明逐帧检查或音轨识别；无法解码时明确说明，不能编造内容。面板“引用到聊天”交出带真实媒体类型的资源，由当前客户端读取。只处理明确引用的素材，不自动发送整个素材库，不额外调用收费模型。系统文件、密钥和账户授权仍由本人处理。

编号是双向引用键。读取同时返回规范名称、当前工程的原生对象句柄、来源版本与文件SHA256；回传导演稿/工坊稿的 references 与 mentions 使用该句柄及来源版本。名称、成员身份、来源或工程变化后重新核对，不能重解析一个同名新对象来冒充原引用。用户仍只需说“视频001”，不需要复制内部ID。原文件通过原有只读租约和磁盘暂存传递，stdio分段编码；不会在内存中缓存整段视频，源文件路径不会交给模型。

支持的视频使用原生分片流与浏览器 MediaSource 播放，可在缓冲范围外重新建立对应时间点的播放流；其他预览按支持情况使用面板私有磁盘文件。完整视频不以JS数组留在内存，解码和播放由浏览器原生媒体控件完成。关闭、切换或读取失败时回收本次播放流与预览资源；读取持续核对工程成员、来源版本及权限，源文件不可读时不借缓存绕过授权。不支持的格式会明确提示，可使用系统默认播放器打开。

面板资源策略仅允许本地生成的 `blob:` 播放地址及 `data:` 内嵌图片，不允许外部网络域名、任意文件地址或嵌套页面。资源策略变更使用新的面板资源版本，避免客户端沿用旧的媒体限制。

## 创作 Skill

插件附带两个 Skill，支持它们的客户端可按需调用：

- **全局导演稿**：在外部聊天生成完整六板块稿件，按宿主实际 Schema 校验并导入原生全局预览，再由用户在 Argo 采纳保存、创建或映射镜头。默认不调用 Argo 内部模型。
- **分镜导演稿**：将聊天中已写好的逐镜稿件，按明确目标写入工坊自定义稿并保存。

Skill 负责输入与工具编排，MCP 提供同一套原生工具；编号解析、批准、保存和回执仍由 Argo 执行。安装插件不会把这两项自动变成 Argo 内部 Bridges 的 Skill 模板。模型调用与媒体生成仍按本次真实授权执行，安装 Skill 本身不提交任务。

外部完整稿导入要求宿主具备 `director.global-preview.external.v1`。缺少该能力时明确拒绝，不自动改用内部 API；原内部生成工具只在用户明确选择时使用。

“打开”及右键新页入口使用另一个原生临时文件缓存：从已授权只读租约分片复制，磁盘预算每连接512 MiB，单个较大视频仍可播放；断开或撤权时回收该连接的副本。外部应用只能取得这份只读副本；原文件路径不交出。应用列表来自 macOS，并在打开前重新检查应用身份、当前连接与素材权限；不接受调用方提供应用路径、启动参数或任意媒体路径。客户端文件页所需的临时副本路径只通过面板私有元数据提供，不进入模型可见正文。这些入口不上传素材。

## 字体

面板和 Argo 使用随包的 HarmonyOS Sans 原版字体。版权归原权利人，原许可见 `LICENSE-update.txt` 以及 Argo“开源组件与许可”。MCP 模型响应、外部客户端自己的按钮和系统授权窗口不由此插件控制字体。

## 安装与更新

插件使用独立版本号。`compatibility.json` 声明所需的应用版本、MCP 协议、业务接口和面板能力。连接时核对应用身份与随包组件。面板标题悬停可查看当前应用版本、build、位置和插件版本；兼容检查不授予工程、媒体或写入权限。

同机有多个 Argo 时，在希望使用的 Argo「设置 → Bridges → 本机MCP」开启本机连接，即选定该应用。独立安装位置也可在本插件目录运行 `./scripts/select-host "/实际安装位置/Argo.app"`。选择保存在本机用户私有记录中，不写入插件包。先完成或取消当前操作；稳定连接层在后续请求时核验新宿主，旧计划和批准不转移。明确选择的目标缺失、签名不符或不兼容时会拒绝连接，不自动改连其他应用。

0.1.0使用稳定连接入口：宿主或面板兼容更新后重验已选应用，并由新包helper建立新连接；客户端stdio入口保留。原生正式公测签名、合同和工程范围校验不变。旧计划与批准失效，未完成写入不自动重试；切换工程仍明确确认。不兼容旧公测需升级，不自动改连其他安装。

从旧入口首次升级到稳定连接层，仍需按AI客户端支持的方式重新加载一次。之后兼容宿主更新不以重启整个客户端为默认步骤。插件manifest、工具定义或Skills更新是否热加载由客户端决定，不能保证所有客户端都实时生效。缺少可选“打开方式”能力时隐藏该入口，素材读取、引用和内置预览仍按其必要合同检查。

安装、停用、更新和卸载优先使用客户端插件管理入口。已安装Codex CLI时，可用 `codex plugin marketplace add .` 注册本地解压源，再用 `codex plugin add argo-studio@argo-studio-local` 安装。GitHub注册的Git源使用 `codex plugin marketplace upgrade argo-studio-local` 刷新，再执行安装命令并核对目标版本；本地ZIP源不支持该刷新命令，需先将源目录更新为新解压包，再执行安装命令。`codex plugin remove argo-studio@argo-studio-local` 只卸载本插件。命令可用性以安装客户端版本为准，不要求手工编辑整份配置。卸载不删除 Argo、工程、素材、API Key 或其他插件。

GitHub 安装源及 Release 下载由发行方提供；仓库可读取不等于已收录到 OpenAI 公共插件目录。

当前桌面客户端使用 `.codex-plugin/plugin.json` 兼容清单和 `mcp.json`。支持 Agent Plugins 格式的客户端可使用 portable 安装包；两种格式不要混放在同一安装目录。

`ARGO_STUDIO_APP` 可显式指定 Argo 安装位置。插件不安装后台常驻服务，也不开放 HTTP/TCP、局域网或公网监听；只通过本机当前用户的连接与 Argo 通信。

插件通过 `select-host` 或 Argo 的“连接插件”选择宿主，安装包不固定机器路径；已有会话仍须核对实际连接身份。

插件自行登记 `argo_mcp`。如果旧的独立同名配置造成连接冲突或“打开方式”缺失，先核对它确属同一个 Argo，再移除旧项；保留其他连接和批准设置。
