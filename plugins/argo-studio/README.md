# Argo Studio

ChatGPT 桌面端的 Argo 素材面板与本机 MCP 整合插件。

工程与素材由正在运行的 Argo 管理。插件不直接读取 AGPK，不接收任意本地文件路径，也不保存另一份素材库。

## 使用

1. 在支持本机插件与 MCP Apps 的 ChatGPT 桌面 Work 模式安装并启用 **Argo Studio**。
2. 打开支持该插件的 Argo，打开工程，在设置中启用本机 MCP。没有显式选择时只查找 `/Applications/Argo.app` 或 `~/Applications/Argo.app`；两个位置同时存在不同安装时，先在 Argo 设置中选择插件宿主。
3. 在侧边打开 **Argo Studio**，查看素材并点击“引用到聊天”，或者在输入框中使用插件提供的素材提及。
4. 在聊天中提供视频、图片或音频，决定采用后说“把这个视频加入 Argo 素材库”。客户端交出真实附件后，插件传递字节；接受本次操作才由 Argo 原生导入并返回实际编号。
   也可打开聊天文件，在“打开方式”中选择 **Argo Studio**，再核对导入。
5. 双击素材在右侧素材库上方居中浮层预览，面板背景轻微模糊，关闭后恢复。视频和音频保留播放及进度控制；“打开”使用 macOS 为该媒体登记的默认应用，旁边箭头直接列出兼容应用，不先跳到文件页。只有明确选择菜单或右键中的“在新页面播放”（图片为“在新页面查看”）才单独打开客户端文件页。播放不再次导入。

素材区只上下滚动并隐藏滑条，搜索栏与底部引用按钮保持固定。客户端文件页自己的顶部菜单由客户端控制；插件内的“打开”直接调用本机已登记应用，不修改该文件页的栏位或系统默认应用。

顶部“添加”用于选择新媒体。悬浮播放器右下角“导入素材”用于将当前素材再加入 Argo 一份：核对本次确认后沿原生导入保存，名称自动加序号。无需新建页面；接受或拒绝后都保留原素材库。准备与保存前重新校验原素材身份和读取权限，不借播放缓存导入。

素材库底部左侧为灰色“复制编号”和“引用到聊天”，右侧“导入素材”将选中成员再入库。多选按已选择的真实对象逐项准备确认，任一取消或失败即停止剩余项；不按列表位置猜对象。手动刷新重新核对列表和缩略图，刷新时提供忙碌反馈。

聊天附件成功入库后先刷新当前素材库；客户端提供关闭当前插件页的能力时，才请求关闭这份临时导入页。在临时文件页手动选择文件并成功导入，也走相同的返回动作；从素材库主页选择文件导入则保留主页。没有客户端关闭能力时保留当前素材库，不新建额外页面，也不声称已经切回先前的标签页。取消、拒绝或失败不会关闭当前页。拒绝确认显示“已取消，未加入素材库”，不展示原始回执JSON。

Argo 退出、工程关闭或本地连接关闭后，面板清空旧素材、选择和预览，并关闭播放器。原宿主重开、原工程恢复且授权仍有效时，本地连接会恢复读取；切换到其他工程仍须确认。后台刷新不调用模型。拒绝更换后不会反复询问，可点击素材区的“更换到…”再次准备确认。

素材名称在同一工程内不重名：重复名称自动加 `(1)`、`(2)`，扩展名保持在最后。已有编号和内部身份不变，外部原文件不改名。旧工程的重复名称在读取时统一显示；下一次新增素材时由原保存系统一并保存，不在打开工程时偷偷写入。

当前客户端若不能提供附件字节或引用上下文，会明确显示未完成；可用面板“添加”选择同一文件。备用文件选择不代表聊天附件自动交接已通过。

聊天引用保留每项完整编号及原生资源身份，不附加重复的说明文本。当前桌面客户端用素材名分别显示引用标签；长编号的批次与候选后缀不裁掉。其他 MCP Apps 客户端可能采用自己的引用外观，但资源名称与身份不变。选择引用不会自动发送消息或覆盖正在输入的文字。

导入成功后的聊天标签同样使用新素材的完整编号；保存回执作为结构化信息随附，不再生成名为“文本”的JSON附件。编号取自本次原生结果，并重新核对当前工程成员身份。

## 权限

连接默认读取当前工程的**全部素材库成员**。工坊、画板、拉片和配乐的结果显式入库后同样可见；尚未入库的生成结果不会自动暴露。源媒体仍须通过 Argo 的授权和文件身份检查，缩略图不代替源文件权限。

附件只接收客户端实际提供的字节，不接受任意磁盘路径。每片最多512 KiB，单文件最多1 GiB、临时合计最多2 GiB；顺序、字节数及 SHA-256 由原生端核对。传递不等于入库。工程写入、批准、防重复和保存回执复用同一套原生工具；取消不返回成功。

界面刷新不调用模型、不上传素材、不提交生成。用户引用编号并要求查看、比较或创作时，`argo_read_asset_media` 读取编号对应的原文件；视频同时从这份原文件自动解码最多8帧，带实际时间点，以模型可读的MCP图片内容交付，不用缓存缩略图替代。图片最长边512像素、每帧最多64 KiB，解码在后台执行、最多等待15秒，不保存持久画面缓存。抽样不能证明逐帧检查或音轨识别；无法解码时明确说明，不能编造内容。面板“引用到聊天”交出带真实媒体类型的资源，由当前客户端读取。只处理明确引用的素材，不自动发送整个素材库，不额外调用收费模型。文件交付和模型理解分别验收。系统文件、密钥和账户授权仍由本人处理。

编号是双向引用键。读取同时返回规范名称、当前工程的原生对象句柄、来源版本与文件SHA256；回传导演稿/工坊稿的 references 与 mentions 使用该句柄及来源版本。名称、成员身份、来源或工程变化后重新核对，不能重解析一个同名新对象来冒充原引用。用户仍只需说“视频001”，不需要复制内部ID。原文件通过原有只读租约和磁盘暂存传递，stdio分段编码；不会在内存中缓存整段视频，源文件路径不会交给模型。

浮层播放每次按512 KiB从原生只读租约读取到面板私有磁盘文件，完整视频不以JS数组留在内存，解码和播放由浏览器原生媒体控件完成。关闭、切换或读取失败时删除本次预览文件；每片都重新核对工程成员、来源版本及读取权限，源文件不可读时不借缓存绕过授权。客户端不支持私有磁盘文件时明确提示，可选择“打开方式”。此缓存不改变Argo原有64 MiB动态热缓存上限。

面板资源策略仅允许本地生成的 `blob:` 播放地址及 `data:` 内嵌图片，不允许外部网络域名、任意文件地址或嵌套页面。资源策略变更使用新的面板资源版本，避免客户端沿用旧的媒体限制。

## 创作 Skill

插件附带两个 Skill，支持它们的客户端可按需调用：

- **全局导演稿**：整理简报与逐镜规划，交由 Argo 当前导演路线生成全局预览，再按原有流程采纳。
- **分镜导演稿**：将聊天中已写好的逐镜稿件，按明确目标写入工坊自定义稿并保存。

Skill 负责输入与工具编排，MCP 提供同一套原生工具；编号解析、批准、保存和回执仍由 Argo 执行。安装插件不会把这两项自动变成 Argo 内部 Bridges 的 Skill 模板。模型调用与媒体生成仍按本次真实授权执行，安装 Skill 本身不提交任务。

“打开”及右键新页入口使用另一个原生临时文件缓存：从已授权只读租约分片复制，磁盘预算每连接512 MiB，单个较大视频仍可播放；断开或撤权时回收该连接的副本。外部应用只能取得这份只读副本；原文件路径不交出。应用列表来自 macOS，并在打开前重新检查应用身份、当前连接与素材权限；不接受调用方提供应用路径、启动参数或任意媒体路径。客户端文件页所需的临时副本路径只通过面板私有元数据提供，不进入模型可见正文。这些入口不上传素材。

## 字体

面板和 Argo 使用随包的 HarmonyOS Sans 原版字体。版权归原权利人，原许可见 `LICENSE-update.txt` 以及 Argo“开源组件与许可”。MCP 模型响应、外部客户端自己的按钮和系统授权窗口不由此插件控制字体。

## 开发与发行

插件使用独立版本号。`compatibility.json` 声明所需的应用版本、MCP协议、业务接口和面板合同范围，以及必要/可选能力；不是按某个候选编号判断。启动后的小型握手再次核对真实宿主、同包helper、资源URI与HTML哈希。面板标题悬停可查看当前连接的应用版本、build、位置和插件版本。兼容检查不授予工程、媒体或写入权限。

同机有多个 Argo 时，在希望使用的 Argo「设置 → Bridges → 本机MCP」点击“连接插件”。独立安装位置也可在本插件目录运行 `./scripts/select-host "/实际安装位置/Argo.app"`。选择保存在本机用户私有记录中，不写入插件包。先完成或取消当前操作；选择改变后正常重载插件会话，旧计划和批准不转移。明确选择的目标缺失、签名不符或不兼容时会拒绝连接，不自动改连其他应用。

更新宿主不要求重装插件：只要所需合同和能力仍兼容，就能继续使用。更新插件与刷新源、当前聊天加载新版是不同步骤。安装或更新后按客户端提示重新加载；不能只凭ZIP已下载判断当前会话已更新。缺少可选“打开方式”能力时隐藏该入口，素材读取、引用和内置预览仍按其必要合同检查。

安装、停用、更新和卸载优先使用客户端插件管理入口。已安装Codex CLI时，可用 `codex plugin marketplace add .` 注册本地解压源，再用 `codex plugin add argo-studio@argo-studio-local` 安装。GitHub注册的Git源使用 `codex plugin marketplace upgrade argo-studio-local` 刷新，再执行安装命令并核对目标版本；本地ZIP源不支持该刷新命令，需先将源目录更新为新解压包，再执行安装命令。`codex plugin remove argo-studio@argo-studio-local` 只卸载本插件。命令可用性以安装客户端版本为准，不要求手工编辑整份配置。卸载不删除 Argo、工程、素材、API Key 或其他插件。

GitHub源及Release下载由发行方另行发布。仓库可读取不等于进入OpenAI公共插件目录；未发布的源和ZIP不冒充已经存在的安装链接。测试与用户包分开，用户ZIP名称只包含插件版本，不包含宿主build。

当前桌面客户端使用 `.codex-plugin/plugin.json` 兼容清单，明确引用同一份 `mcp.json`。打包脚本默认生成此格式；源码保留 Agent Plugins 清单，可通过 `--format portable` 导出。两种格式不混放在同一个安装目录，避免当前客户端只读到展示信息却遗漏工具。安装/升级后须重新加载插件；当前客户端未提供热重载时，由用户正常重开客户端。

`ARGO_STUDIO_APP` 仅供显式指定安装位置或隔离验收；便携发行包不带候选路径。插件不安装后台常驻服务，不打开 HTTP/TCP、局域网或公网监听。原生 stdio helper 通过当前用户 Unix 通信连接匹配的 Argo Host。

插件安装后由插件自身登记 `argo_mcp`。旧的独立同名 MCP 配置会遮住插件连接归属，导致工具可调用但文件“打开方式”缺失；仅在核对该项确为同一个 Argo 后移除旧项，不改其他连接或批准策略。启动脚本以插件目录为工作目录使用 `./scripts/launch-mcp`，不依赖兼容加载器未展开的 `${PLUGIN_ROOT}` 命令路径。

本地插件验收不等于公共插件目录审核通过；本机 MCP 公开提交还受客户端平台的发布资格限制。
